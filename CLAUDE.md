## 🎯 What this repo is

The iOS SDK component of the **Beeping Platform** ecosystem. A Swift 6
library (target) that exposes a modern actor-based API to encode and decode
short payloads transmitted over sound (audible + ultrasonic), running locally
via ObjC++ bridge to `beeping-core` or remotely via the `beepbox` HTTP server.

**Source of truth for scope and timeline**:

- 📄 `docs/PRODUCTO.md` — product spec (read this before any non-trivial change)
- 📅 `docs/ROADMAP.md` — live timeline
- 📜 `docs/ROADMAP_CHANGELOG.md` — append-only history of timeline changes

## 🌳 Branch model

Per global methodology:

- `develop` — base branch. **Never commit directly** (except during `/worktree-init` bootstrap, which is the one documented exception).
- `main` — release branch. Auto-managed by release-please once activated (Phase 9 BEE-82).
- **Milestone mode** (default for Phase 9): single shared branch `milestone/phase-9`,
  N commits (one per BEE-task), one PR at the end → `develop`.
- **Individual task mode**: branch per task, e.g. `feat/bee-70-actor-api`,
  one PR per task → `develop`.

Branch protection (PR + 1 review + linear history + signed commits + no force push)
becomes active after BEE-67 closes.

## 🧪 Testing strategy (target)

- **Unit (legacy)**: XCTest (preserved during BEE-68 migration)
- **Unit (modern)**: Swift Testing (`@Test`, parametrized) — Xcode 16+ required
- **Snapshot**: swift-snapshot-testing (PointFree) for SwiftUI views + JSON serializations
- **Property-based**: SwiftCheck for encoder/decoder invariants
- **UI E2E**: XCUITest in `BeepingSampleApp` (sample app, BEE-78)
- **Coverage**: ≥80% line coverage on target `Beeping`
- **Strict concurrency**: compile with `-strict-concurrency=complete`, 0 warnings

CI gates (BEE-76 + BEE-77):

1. `swift build -Xswiftc -strict-concurrency=complete` → 0 warnings
2. `xcodebuild test -scheme Beeping -destination 'platform=iOS Simulator,name=iPhone 15'` → all pass
3. `swiftlint --strict` → 0 violations
4. `swift-format lint --strict --recursive Sources Tests` → 0 issues
5. Coverage report uploaded as artifact

## 🚫 Things to never do

- ❌ Reintroduce singleton `[Beeping instance]` API in the new Swift target.
- ❌ Use `@unchecked Sendable` to silence strict concurrency warnings — fix the actual data race.
- ❌ Vendor new `.a` / `.dylib` / `.framework` binaries from anywhere except a pinned `beeping-core` release tag (post-BEE-79).
- ❌ Hardcode API keys or secrets — always `.env.local` or build args.
